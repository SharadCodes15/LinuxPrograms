## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/linux-programs.git
cd linux-programs
```

Compile a C program:

```bash
gcc program.c -o program
```

Run it:

```bash
./program
```

For programs requiring POSIX threads:

```bash
gcc program.c -o program -pthread
```

For C++:

```bash
g++ program.cpp -o program
./program
```

For shell scripts:

```bash
chmod +x script.sh
./script.sh
```
